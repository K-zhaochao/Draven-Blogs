``` java
public class Client {  
    // 客户端  
    static void main() throws IOException {  
        // 客户端：多次发送数据  
        // 服务器：接收多次接收数据，并打印  
  
        // 1.创建 Socket 对象并连接服务器  
        Socket socket = new Socket("127.0.0.1", 10000);  
  
        // 2.写出数据  
        Scanner sc = new Scanner(System.in);  
        OutputStream os = socket.getOutputStream();  
  
        try {  
            while (true) {  
                System.out.print("请输入您要发送的信息：");  
                String msg = sc.nextLine();  
                if ("886".equals(msg)) {  
                    break;  
                }  
                os.write(msg.getBytes(StandardCharsets.UTF_8));  
            }  
        } finally {  
            // 3.释放资源  
            socket.close();  
        }  
    }  
}
```

``` java
public class Server {  
    // 服务端  
    static void main() throws IOException {  
        // 客户端：多次发送数据  
        // 服务器：接收多次接收数据，并打印  
  
        // 1.创建 ServerSocket 对象绑定10000端口  
        ServerSocket serverSocket = new ServerSocket(10000);  
  
        // 2.等待客服端来连接  
        Socket socket = serverSocket.accept();  
  
        // 3.读取数据  
        InputStreamReader reader = new InputStreamReader(socket.getInputStream());  
        int b;  
        try {  
            while ((b = reader.read()) != -1) {  
                System.out.print((char) b);  
            }  
        } finally {  
            // 4.释放资源  
            socket.close();  
            serverSocket.close();  
        }  
    }  
}
```

## 题目二：

### 题目：

![[Draven_Note_Images/Pasted image 20260610130022.png]]
**注意：** 此题讲述了 `socket.shutdownOutput()` 结束标记的使用。

### 代码实现：

``` java
public class Client {  
    // 客户端  
    static void main() throws IOException {  
        // 客户端：发送一条数据，接收服务端反馈的消息并打印  
        // 服务器：接收数据并打印，再给客户端反馈消息  
  
        // 1.创建 Socket 对象并连接服务器  
        Socket socket = new Socket("127.0.0.1", 10000);  
  
        // 2.写出数据  
        String str = "你好你好";  
        OutputStream os = socket.getOutputStream();  
        os.write(str.getBytes(StandardCharsets.UTF_8));  
  
        // 写一个结束标记  
        socket.shutdownOutput();  
  
        // 3.接受服务端的回写数据  
        int b;  
        InputStreamReader reader = new InputStreamReader(socket.getInputStream());  
        while ((b = reader.read()) != -1) {  
            System.out.print((char) b);  
        }  
  
        socket.close();  
    }  
}
```

``` java
public class Server {  
    // 服务端  
    static void main() throws IOException {  
        // 客户端：发送一条数据，接收服务端反馈的消息并打印  
        // 服务器：接收数据并打印，再给客户端反馈消息  
  
        // 1.创建 ServerSocket 对象绑定10000端口  
        ServerSocket serverSocket = new ServerSocket(10000);  
  
        // 2.等待客服端来连接  
        Socket socket = serverSocket.accept();  
  
        // 3.读取数据  
        int b;  
        InputStreamReader reader = new InputStreamReader(socket.getInputStream());  
        // 细节：  
        // read方法会从连接通道中读取数据  
        // 但是，需要有一个结束标记，此处的循环才会停止  
        // 否则，程序就会一直停在read方法这里，等待读取下面的数据  
        while ((b = reader.read()) != -1) {  
            System.out.print((char) b);  
        }  
  
        // 4.回写数据  
        String str = "你好，我已收到。";  
        socket.getOutputStream().write(str.getBytes(StandardCharsets.UTF_8));  
  
        socket.close();  
        serverSocket.close();  
    }  
}
```
